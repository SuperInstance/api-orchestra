# API Orchestra — Using every API, every model

A creative anthology built with extensive API use:

- **6 Z.AI models** (GLM-4.6, 4.7, 5.1, 5.2, 5.3, 5.3-Flash)
- **192 DeepInfra models** (chat, embeddings, image, video, audio, vision, ASR, TTS)
- **Cloudflare AI** (308 models including Aura-2 TTS, GLM-5.3, image gen, embeddings)
- **Parallel orchestration** via Python subagents

## What this is

A demonstration of how to compose multiple APIs and models for a single creative project.

Each "movement" uses a different set of models, different modality, different cross-pollination.
